# Game of Death — Build Notes
## What This Is
Multi-rule cellular automaton explorer for Precursor.
## Key Decisions
- Generalized B/S rule engine (not just B3/S23)
- 12 classic Life-like rules with notation display
- Shares grid/rendering architecture with Conway's Life
- Random fill as default start, editor for custom patterns
- 3 states: RuleSelect, Running, Editor
